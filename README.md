# Lumi Pop

«Шарики» (bubble shooter) из светящихся сфер.

## Что внутри (v2)

- **Режимы:** бесконечный; приключение (60 уровней, цели: очистить небо, собрать звёзды, набрать очки; 1–3 звезды); челлендж дня (одно поле для всех, 45 выстрелов).
- **Особые шары:** лёд (тает со второго раза), камень (не лопается, только падает), хамелеон (меняет цвет каждый ход), бомба (взрывается, если рядом лопнули шары), звёздный шар (цель уровня). В приключении появляются с уровней 5, 8, 11, 14, 20; в бесконечном — по мере роста счёта.
- **Бустеры:** огненный шар (насквозь до потолка), молния (сжигает ряд), радуга. Клавиши 1, 2, 3.
- **Мета:** искры (валюта), 3 задания в день, подарок за серию входов (7 дней), магазин скинов шаров (4) и фонов (4), рекорды (свои + мировой рейтинг на Яндексе).
- **Удержание:** уровень игрока (опыт за каждую партию, награда за каждый уровень, крупная — каждый 5-й), сундук раз в 4 часа (за рекламу — сразу), 6 созвездий из звёзд приключения с наградами, «до рекорда не хватило N», ярлык на рабочий стол (Яндекс) / избранное (VK) за +50 искр, запрос оценки на Яндексе после рекорда или хорошей победы.
- **Музыка:** своя мелодия (шкатулка + пианино перебором, 72 BPM, до мажор), генерируется в коде, отдельная кнопка. Есть проигрыватель бесшовной петли из файла: `python3 tools/make_music.py трек.wav` кладёт `vendor/music.mp3` и отпечаток начала, сборка подхватит сама.

Исходники: `platform.js` (площадки), `audio.js` (звук и музыка), `i18n.js` (тексты ru/en), `levels.js` (генератор уровней и челленджа), `meta.js` (прогресс), `game.js` (поле), `menus.js` (экраны). PixiJS 8 (WebGL), без картинок и звуковых файлов: шары, фон и эффекты рисуются кодом, звук синтезируется. Вся игра весит около 0,8 МБ в распакованном виде.

## Сборка

```
python3 build.py
```

В `dist/` появятся папки и архивы для каждой площадки, а архивы для четырёх площадок скопируются в `build/`:

| Архив | Площадка | SDK подключается |
|---|---|---|
| `lumipop-yandex.zip` | Яндекс Игры | `/sdk.js` (как велит документация Яндекса) |
| `lumipop-vk.zip` | VK Игры / OK | VK Bridge с unpkg, версия 2.15.2 — **сверьте актуальную версию** перед загрузкой |
| `lumipop-crazygames.zip` | CrazyGames | `crazygames-sdk-v3.js` |
| `lumipop-poki.zip` | Poki | `poki-sdk.js` v2 |
| `lumipop-web.zip` | свой сайт / демо | без SDK, реклама заменена демо-заглушкой |

В каждом архиве `index.html` лежит в корне, имена файлов только латиницей и без пробелов.

## Как игра говорит с площадкой

Весь код площадок лежит в `src/platform.js`. Игра вызывает только его:

- `ready()`: игра загружена (Яндекс `LoadingAPI.ready`, Poki `gameLoadingFinished`, CrazyGames `loadingStop`).
- `gameplayStart()` / `gameplayStop()`: на первом касании партии и на паузе / конце игры.
- `interstitial()`: полноэкранная реклама только по кнопке «Ещё раз» и не чаще раза в 60 секунд. Звук и игра на паузе.
- `rewarded()`: два места, оба по желанию игрока. «Продолжить» после проигрыша (раз за партию) и радужный шар (раз в минуту).
- `save()` / `load()`: localStorage сразу и облако с задержкой 0,6 с (Яндекс `player.setData`, CrazyGames `data`, VK `VKWebAppStorageSet`). Сохраняется каждый ход.
- Язык: SDK Яндекса или `vk_language`, иначе язык браузера. Русский для ru/be/kk/uk/uz, для остальных английский.
- Звук выключается при потере фокуса, сворачивании вкладки и событиях паузы площадки.

## Перед загрузкой: чек-лист

**Яндекс Игры**
- В черновике включить облачные сохранения (п. 1.11).
- Создать лидерборд с техническим названием `lumipopEndless` (тип «числовой», больше — лучше). Без него вкладка «Мир» в рекордах покажет «Пока пусто».
- Ориентация: портретная и альбомная, игра подстраивается под обе.
- Иконка и обложка рисуются отдельно, скриншот на них ставить нельзя (п. 5.6).
- Название «Lumi Pop» одинаковое на всех языках (п. 5.1.3).

**VK Игры / OK**
- Сохранение режется на части по 1000 символов: у VK лимит 4096 байт на ключ.
- Проверить версию VK Bridge и что `VKWebAppShowNativeAds` с форматом `reward` разрешён для приложения.
- Ролик за награду запускается только по кнопке, это и есть согласие игрока.

**CrazyGames**
- Сначала «Basic launch»: реклама там отключена, кнопки за рекламу покажут «Реклама сейчас недоступна». Это нормально.
- Для «Full launch» SDK уже подключён: события геймплея, сохранения, реклама.
- Своей кнопки полноэкранного режима нет, как требует площадка.

**Poki**
- Подача через форму Poki for Developers, дальше их тесты на живых игроках.
- Первая загрузка ~0,74 МБ при лимите 8 МБ. Внешних запросов, кроме SDK, нет: шрифт и библиотека лежат в архиве.

## Тесты

`bash test/run.sh` — сборка и прогон в браузере (нужны `pip install playwright` и `playwright install chromium`).

## Отладка

`index.html?debug` открывает `window.__lumi`: прицел, выстрел, добавление рядов, состояние игры. Без `?debug` объект не создаётся.

## Шары

Нарисованные шары лежат в `vendor/orbs.png` (атлас 4×4 по 128 px, номер ячейки = код шара). Исходный лист — `tools/orbs-sheet.png`; пересобрать атлас: `python3 tools/make_orbs.py tools/orbs-sheet.png`. Если атласа нет, игра рисует шары кодом. Скины из магазина (Леденцы, Самоцветы, Планеты) рисуются кодом.

## Шрифт

Inter Display ExtraBold, урезанный до латиницы и кириллицы (`vendor/lumi.woff`). Лицензия SIL Open Font License 1.1.

## Git

Проще всего: дважды щёлкните `push-to-github.bat`. Он пересоберёт архивы в `build/` (если установлен Python), спросит, что изменилось, сделает коммит и отправит на https://github.com/Sacredz58/lumipop.

Вручную — выложить на GitHub (создайте пустой репозиторий `lumipop` у себя в аккаунте, без README):

```
git remote add origin https://github.com/<ваш-логин>/lumipop.git
git push -u origin main
```

Готовые архивы для площадок лежат в `build/` и обновляются командой `python3 build.py` (после неё закоммитьте изменения). Папка `dist/` — промежуточная, в git не входит.
